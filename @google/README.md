# `@google` — Google Dorks (Classic)

> **Atdork-DB package folder** · [Browse in the web catalog](https://amnottdevv.github.io/Atdork-DB/#/f/google) · Part of [Atdork-DB](https://github.com/amnottdevv/Atdork-DB)

Large classic Google dork collections, kept as-is from their original authors.

## Packages

| Package | Dorks | Description |
| --- | ---: | --- |
| `googledorks1.txt` | 13,760 | Classic curated collection (BullsEye) |
| `googledorks2.txt` | 18,463 | ~7K dorks for exposed site internals |

**Folder total: 32,223 dorks across 2 packages.**

## Usage

```bash
atdork install @google                # install the whole folder
atdork install @google/googledorks1.txt      # install a single package
atdork --database-dork @google --database-preview   # preview as queries
```
